## 🛠️ How to View & Test Locally

You can open the portfolio immediately in any browser with zero setup:
1. Double-click `index.html` to open the interactive web portfolio.
2. Double-click `deck.html` to open the slide presentation deck.

Or run a local static server using Node.js:
```bash
npx serve .
# or
npx http-server .
```

## 🌐 How to Deploy Live to Send to Clients

### Option A: Free Deployment via Vercel (1 Minute)
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in this folder and press enter for default prompts.
3. You will receive an instant live URL (e.g., `innoaivators-portfolio.vercel.app`) that you can also link to your custom domain like `portfolio.innoaivators.com`!

### Option B: Free Deployment via Netlify
1. Drag and drop the `innoaivators portfolio` folder directly into [Netlify Drop](https://app.netlify.com/drop).
2. It goes live instantly with an HTTPS link.

### Option C: Traditional cPanel / Shared Hosting
1. Upload all files (`index.html`, `deck.html`, `style.css`, `app.js`) to your `public_html/portfolio/` folder via FTP or File Manager.
2. Your portfolio will be accessible at `https://innoaivators.com/portfolio/`.

## 📄 How to Save as a PDF Document for Clients
1. Open either `index.html` or `deck.html` in Google Chrome or Microsoft Edge.
2. Click the **"Print / PDF"** button in the header (or press `Ctrl + P`).
3. Set Destination to **"Save as PDF"**.
4. Check **"Background graphics"** under More Settings.
5. Click **Save** to generate a clean, branded corporate PDF document ready to email or attach in WhatsApp!
